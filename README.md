# 통닭사줘 (S-LQB-060) 로봇 주행 영상

2026 로보틱스 챌린지 문제해결트랙 예선 주행 영상을 보여주는 페이지입니다.

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만듭니다 (Public).
2. **Add file → Upload files** 로 이 폴더의 `index.html`, `README.md`, `videos` 폴더를 통째로 끌어다 놓고 Commit.
3. **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)` 로 저장.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속.

## 영상 바꾸기
`videos/` 폴더의 mp4를 같은 이름으로 덮어쓰면 됩니다. (H.264 mp4 권장, 파일당 100MB 이하)
